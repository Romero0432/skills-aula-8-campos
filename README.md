# Skills Aula 8 Campos

Contenido de las ocho tarjetas de la clase de skills de MenteOut.ai: cada alumno es un grupo de tres skills, con sus textos, comandos y decisiones.

## Tarjetas

| Nº | Alumno | Rol | Skills |
|---|---|---|---|
| 01 | [Marketing](tarjetas/01-marketing.md) | Estrategia y crecimiento | Plan de campaña, Contenido por canal, Informe de rendimiento |
| 02 | [Webs](tarjetas/02-webs.md) | Diseño y desarrollo web | Diseño frontend, Revisión de accesibilidad, Páginas publicadas |
| 03 | [Prompts](tarjetas/03-prompts.md) | Instrucciones claras para la IA | Prompts de imagen, Prompts de vídeo, Vocabulario técnico |
| 04 | [Vídeo y visual](tarjetas/04-video-visual.md) | Imagen, vídeo y diseño | Identidad visual, Recursos visuales, Crítica de diseño |
| 05 | [Escritura](tarjetas/05-escritura.md) | Textos con voz propia | Voz y redacción, Revisión de marca, Borradores por canal |
| 06 | [Documentos](tarjetas/06-documentos.md) | Documentos, hojas y presentaciones | Word, Excel, PowerPoint |
| 07 | [Automatización](tarjetas/07-automatizacion.md) | Tareas sin repetir | Resumen diario, Google Workspace, Navegador |
| 08 | [Delegado](tarjetas/08-delegado.md) | Organiza la clase y crea skills | Crear skill, Crear plugin, Adaptar plugin |
